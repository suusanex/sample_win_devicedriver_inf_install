# Windows デバイスドライバ INF インストーラ コンソールアプリケーション

## 機能概要
INF ファイルを使用して Windows デバイスドライバをインストールするスタンドアロンコンソールアプリケーション。開発者がドライバインストールを独立してテストできるようにし、他のインストーラソリューションに統合可能な再利用可能なロジック層を提供します。実装は Microsoft の最新 Windows デバイスドライバベストプラクティスに従い、HLK（Hardware Lab Kit）テストおよび認証プロセスとの互換性を確保します。

## ユーザーシナリオ & テスト *(必須)*

### 主要なユーザーストーリー
Windows デバイスドライバ開発者として、開発中にドライバインストールプロセスをテストし、エンドユーザーに信頼性の高いインストールメカニズムを提供するために、INF ベースのデバイスドライバをインストールできるコンソールアプリケーションが必要です。

### 受け入れシナリオ
1. **前提条件** 有効な INF ファイルとドライバパッケージが存在する、**実行時** ユーザーが INF ファイルパスを指定してコンソールアプリケーションを実行する、**期待結果** ドライバが正常にインストールされ、システムがデバイスを認識する
2. **前提条件** 無効または破損した INF ファイルが存在する、**実行時** ユーザーがインストールを試行する、**期待結果** アプリケーションが問題を説明する明確なエラーメッセージを日本語で表示する
4. **前提条件** ドライバが既にインストールされている、**実行時** ユーザーが同じドライバのインストールを試行する、**期待結果** アプリケーションが既存インストールを検出し、適切な選択肢（更新、再インストール、またはスキップ）を提供する
5. **前提条件** アプリケーションがインストールを完了する、**実行時** プロセスが終了する、**期待結果** アプリケーションがインストール状況を表示し、検証のためのガイダンスを提供する

### エッジケース
- INF ファイルが不足しているドライバファイルを参照している場合はどうなるか？
- システム再起動が必要なドライバをシステムはどのように処理するか？
- Windows ドライバ署名ポリシーがインストールをブロックした場合はどうなるか？
- アプリケーションは同時実行されるドライバインストールをどのように処理するか？

## 要件 *(必須)*

### 機能要件
- **FR-001**: システムは提供された INF ファイルを使用して Windows デバイスドライバをインストールしなければならない
- **FR-004**: システムは明確なステータスメッセージとエラー報告を日本語で提供しなければならない
- **FR-006**: システムは HLK 互換性のために Microsoft 推奨のデバイスドライバインストール実践に従わなければならない
- **FR-007**: システムはソースコードを読まずに使用できるコマンドラインインターフェースを提供しなければならない
- **FR-008**: システムは前提条件とシステム要件をユーザーに表示しなければならない
- **FR-009**: システムは他のインストーラでの再利用のために、分離可能なコンポーネントとしてドライバインストールロジックを実装しなければならない
- **FR-010**: システムはトラブルシューティングのためにインストール活動をログに記録しなければならない
- **FR-012**: システムはサイレントモードのインストールをサポートしなければならない
- **FR-013**: システムは実行可能な次のステップとともに明確な成功/失敗フィードバックを提供しなければならない
- **FR-014**: システムはドライバインストールロジック内では、保守用のトレースログも含めて全て英語での出力を行う。UIでの日本語のステータスメッセージやエラー報告は、そのロジックとは分離してUI側で実装しなければならない
- **FR-015**: **ファイルシステム・ミニフィルタ、クラス単位のフィルタ、ソフトウェア（仮想）デバイス**など、**ハードウェア I/O デバイスを直接制御しないドライバに限定**します。それ以外のハードウェア依存型ドライバ（物理デバイス／バス／ミニポートなど）は対象外です。

### 非機能要件
- **NFR-001**: アプリケーションは Windows 10 および Windows 11 と互換性がなければならない
- **NFR-002**: アプリケーションは .NET 10 フレームワークをターゲットにしなければならない
- **NFR-003**: インストールプロセスは合理的な時間制限内で完了しなければならず、それを超える場合はタイムアウトを検出してエラーとしなければならない
- **NFR-004**: アプリケーションは日本語でユーザーインターフェースを提供しなければならない
- **NFR-005**: コードは他のプロジェクトのためにインストールロジックの抽出を可能にするように構造化されなければならない

### 主要エンティティ *(データが関与する場合に含める)*
- **INF ファイル**: インストール手順とドライバメタデータを含むデバイスドライバ情報ファイル
- **ドライバパッケージ**: デバイスインストールに必要なドライバファイル、INF ファイル、および関連リソースのコレクション
- **インストールセッション**: 関連するログとステータスを持つドライバインストールプロセスの単一実行
- **デバイスインスタンス**: インストールされたドライバに関連付けられる特定のハードウェアデバイス

## 技術的制約
- Microsoft Windows Hardware Lab Kit（HLK）要件に準拠する必要がある
- 2024年時点の Windows ドライバインストールベストプラクティスに従う必要がある
- 署名済みおよび未署名ドライバの両方で動作する必要がある（適切な警告付き）

## 依存関係と前提条件
- 適切なドライバインストール API が利用可能な Windows オペレーティングシステム
- 必要に応じてユーザーが管理者権限を持っているか取得できる
- INF ファイルが標準の Windows INF 形式仕様に従っている
- ターゲットデバイスが提供されたドライバと互換性がある
